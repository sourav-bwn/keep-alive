How saving works

Saving writes a small file (config.json) in the GitHub repo. The pinger reads it on every run, so changes apply within 10 minutes. To save from this page, paste a GitHub token once. It is stored only in this browser and is sent only to GitHub (api.github.com) when you press Save. It is never written into the repo or sent anywhere else.

Create a "fine-grained token" for only the keep-alive repo with Contents: Read and write.
